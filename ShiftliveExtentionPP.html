CHROME EXTENSION – SHIFTLIVE RIDE CHAT Shift Live Ltd. also provides a Chrome browser extension named "ShiftLive Ride Chat" (the “Extension”). The Extension is designed to allow authorized ShiftLive web users to send chat messages to selected rides within the ShiftLive system. Data Accessed by the Extension The Extension temporarily accesses the following session-based data from active ShiftLive web pages: Authorization header (access token) Customer ID Ride identifiers (Ride IDs) This data is accessed solely to enable ride chat functionality within the ShiftLive system. Data Storage The Extension does not store personal data externally. All accessed data is stored temporarily in memory during the active browser session and is automatically cleared when the extension popup is closed or the relevant browser tab is closed. Data Sharing The Extension does not transmit, sell, or share collected data with any third parties. All communication occurs directly between the user’s browser and ShiftLive servers.
